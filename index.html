Welcome to the Portal

This is the personal web space of untrustedinstaller - a small corner of the internet built the way it used to be built: plain hand-coded HTML 4.01, a table-based layout, CSS 1, and not a single line of JavaScript.

The site is designed to render natively on vintage machines - Windows 98 running IE 5.5 or RetroZilla - while still looking clean on modern computers. No frames, no plugins, no tricks. Point, click, done.
